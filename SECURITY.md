# Security policy

## Supported versions

This repository is the G-A-R-D-E-N Godot fork. Security fixes for this fork are made on the default branch. Older development builds may not receive fixes.

## Reporting a vulnerability

Prefer the **Report a vulnerability** form on the repository [Security tab](https://github.com/G-A-R-D-E-N/godot/security/advisories/new). If that form is unavailable, contact the [G-A-R-D-E-N](https://github.com/G-A-R-D-E-N) organization through GitHub private channels rather than opening a public issue or pull request. Do not publish vulnerability details, credentials, or proof-of-concept exploits in public issues or pull requests.

Include the affected version or commit, the potential impact, and steps to reproduce. Please avoid including personal data or game files.

The maintainers will review reports and coordinate fixes and disclosure with the reporter when practical. There is no published response-time guarantee or bug bounty.
